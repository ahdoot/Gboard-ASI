Engineered Beyond Standard Typing

Gboard Pro breaks through manufacturer lock-ins, granting every Android user the complete, unfiltered flagship Google typing suite.

🎙️

Gemini Rambler Conversational Voice Dictation

Transcribe live speech naturally without having your vocal stumbles recorded. Rambler cleans up speech syntax in real time.

  • Automated speech filler removal ("uh", "um", "you know")
  • Mid-sentence thought correction ("meet at 4, actually make it 5")
  • 1.5-second screen rotation grace period prevents session cutoffs
  • Strict language policy eliminates unintended multilingual drift
🤖

AI Writing Tools & Tone Restyler

In-line Gemini intelligence built right into the keyboard strip for instant proofreading and stylistic transformations.

  • One-tap proofread for typos, syntax, and grammatical nuance
  • Adaptive tone switcher: Professional, Casual, Concise, Emotive
  • Stable Google Server backend eliminates "cannot connect" errors
  • Direct Boot safety prevents cold device reboot lockups
🎨

Material 3 Expressive & AMOLED Black

Stunning tactile visual palettes and battery-saving pure pitch black surfaces designed for high-resolution OLED screens.

  • Signature Blush Lilac pastel palette replicating showcase.png
  • Cotton Candy, Sunset Peach, and Fresh Mint curated themes
  • AMOLED Pure Black (#000000) mode for zero backlight bleed
  • Dynamic Monet wallpaper extraction on Android 12L to 16
📋

24-Hour Clipboard & 100-Clip Buffer

Overhaul the restrictive 1-hour clipboard limit. Never lose copied phone numbers, addresses, code snippets, or links again.

  • Unpinned clips preserved for 24 hours by default (was 1 hour)
  • History buffer capacity expanded from 5 to 100 recent clips
  • Discrete 5-step slider: 1 hour, 24 hours, 7 days, 30 days, Never
  • Dynamic localized pin tip explanations across 83 languages
🛡️

Zero Root & Harmonious Coexistence

Enjoy flagship capabilities without modifying device firmware or compromising system banking integrity.

  • Installs under com.gboardpro.app alongside factory Gboard
  • Zero Root, Magisk, or unlocked bootloader requirements
  • No background telemetry or third-party ad frameworks
  • Device-Protected Storage ensures on-device privacy
🔄

Automated Background Update Checks

A built-in maintenance daemon keeps your keyboard updated with the latest stability enhancements without Play Store delays.

  • Automated 8-hour background query against GitHub releases
  • Instant Android notification when new versions drop
  • Integrated download speed meter with real-time transfer stats
  • One-tap in-app package installer launch

Quick Setup

Install in 3 Simple Steps

No root, no custom recovery, and no complex terminal commands required.

1

Download APK

Get the official verified signed release Gboard_Pro.apk (v2.0.7) directly from GitHub Releases.

2

Install Package

Open the APK on your device, allow unknown sources if prompted, and complete the standard Android installation.

3

Activate in Settings

Navigate to Settings > System > Languages & input > On-screen keyboard and switch Gboard Pro to ON.
